# Manage transit gateway tags in AWS Transit Gateway

Add tags to your resources to help organize and identify them, such as by purpose,
owner, or environment. You can add multiple tags to each transit gateway. Tag keys must be
unique for each transit gateway. If you add a tag with a key that is already associated with
the transit gateway, it updates the value of that tag. For more information, see [Tagging your Amazon EC2\
Resources](../../../ec2/latest/userguide/using-tags.md).

###### Add tags to a transit gateway using the console

1. Open the Amazon VPC console at
    [https://console.aws.amazon.com/vpc/](https://console.aws.amazon.com/vpc).

2. On the navigation pane, choose **Transit**
**Gateways**.

3. Choose the transit gateway that you want to add or edit tags for.

4. Choose the **Tags** tab in the lower part of the
    page.

5. Choose **Manage tags**.

6. Choose **Add new tag**.

7. Enter a **Key** and **Value** for the
    tag.

8. Choose **Save**.
