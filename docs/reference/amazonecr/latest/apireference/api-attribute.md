# Attribute

This data type is used in the [ImageScanFinding](api-imagescanfinding.md) data type.

## Contents

**key**

The attribute key.

Type: String

Length Constraints: Minimum length of 1. Maximum length of 128.

Required: Yes

**value**

The value assigned to the attribute key.

Type: String

Length Constraints: Minimum length of 1. Maximum length of 256.

Required: No
