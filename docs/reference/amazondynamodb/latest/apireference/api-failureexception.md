# FailureException

Represents a failure a contributor insights operation.

## Contents

###### Note

In the following list, the required parameters are described first.

**ExceptionDescription**

Description of the failure.

Type: String

Required: No

**ExceptionName**

Exception name.

Type: String

Required: No
