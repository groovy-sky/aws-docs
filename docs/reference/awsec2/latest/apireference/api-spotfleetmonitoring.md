# SpotFleetMonitoring
<a name="API_SpotFleetMonitoring"></a>

<a name="API_SpotFleetMonitoring_Contents"></a>

 ** Enabled ** (request), ** enabled ** (response)

Default: `false`
Type: Boolean
Required: No
